Импорт без повторов

Загрузи свои партии дважды и проверь, почему число игр не удвоилось.

Ориентир: 15 минутТвой датасетПроверка → сохранение

Результат: умеешь найти путь импортируемой партии от файла до записи по game ID и объяснить, почему предварительный просмотр ещё не меняет базу.

Одна строка — одна партия

NDJSON содержит отдельный JSON-объект на каждой непустой строке. data/dataset-import.js читает строки, а data/normalize-game.js оставляет нужные поля завершённых rated standard партий твоего профиля. Партии другого профиля и повреждённые записи дают ошибку до сохранения.

Файл → проверка и нормализация → предварительный отчёт
Кнопка «Сохранить историю» → транзакция IndexedDB
  game ID отсутствует → добавить
  game ID уже есть → оставить существующую запись

Одинаковые ID внутри файла проверяются отдельно: одинаковая нормализованная запись — повтор, противоречащая — ошибка. В базе games ключ записи — id. Весь пакет записывается одной транзакцией; ошибка отменяет пакет. MDN: ключи и транзакции IndexedDB.

Предскажи и проверь

  1. Перезагрузи addon через Reload в about:debugging. Открой основной экран из popup.
  2. Отметь тренировку, если сегодня уже выполнил задание; запомни её статус.
  3. В разделе истории выбери /home/joerude/Desktop/lichess_dataset/games/games_raw.ndjson и необязательный rating_history.json из корня датасета.
  4. Нажми Проверить файлы. Ожидается: 6 430 строк, 6 429 уникальных партий, один повтор и 474 точки рейтинга при выборе обоих файлов. До сохранения таблица не меняется.
  5. Нажми Сохранить историю. Сверь: Bullet — 5 917, Blitz — 345, Rapid — 167. Переключи график между контролями и Puzzles.
  6. Перед повторной загрузкой запиши прогноз: сколько партий добавится? Повтори проверку и сохранение. Ожидается 0 новых и 6 429 уже существующих.
  7. Закрой и открой вкладку снова. Проверь историю и прежний статус сегодняшней тренировки.

Этот набор заканчивается 15 марта 2026 года. График показывает прошлую историю; новые партии пока нужно импортировать из файла.

Найди правило в коде

Начни с history.import в extension/app/history.js, затем открой importHistory в extension/data/repository.js. Найди проверку существующего game ID и момент, когда операция сообщает об успехе.

Теперь измени заголовок секции истории в extension/ui/dashboard.html, сохрани файл и нажми Reload. Проверь новый текст и сохранённое число партий. Это упражнение показывает, что HTML страницы и данные базы живут отдельно.

Вспомни без кода

Что защищает историю от удвоения после повторного импорта?

Объясни своими словами: что изменится после предварительного просмотра, что после сохранения, что останется при ошибке в последней строке?

Подсказка после попытки

Просмотр меняет только интерфейс. Успешное сохранение добавляет отсутствующие партии и сохраняет выбранные рейтинги. Ошибка файла обнаруживается до транзакции, поэтому прежняя база сохраняется.

На следующем занятии

Без чтения кода восстанови путь файл → нормализация → транзакция. Затем можно перейти к API: получать новые партии и повторно проверять уже знакомые ID.

Резервная копия в этой версии содержит отметки тренировок. Историю партий можно заново импортировать из исходного датасета.
