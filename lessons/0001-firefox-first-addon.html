Lichess Training · Firefox · Урок 01

Своя кнопка в браузере

Создай небольшой учебный addon: нажимаешь кнопку Firefox и видишь карточку «Решить 5 задач». Затем меняешь текст и проверяешь результат.

Ориентир: 10–15 минутДва файлаHTML + JSON

Результат: ты можешь загрузить расширение, объяснить связь manifest с popup и изменить карточку. Это первый шаг к собственной программе тренировок.

Manifest

manifest.json сообщает Firefox имя, версию и устройство расширения. Поле action.default_popup указывает, какую HTML-страницу открыть по нажатию кнопки.

Mozilla: action и default_popup

Popup

popup.html задаёт содержимое карточки. Имя файла выбираешь ты; оно должно совпадать с путём в manifest.

На следующем этапе добавим действие «Выполнено» и сохранение прогресса.

1. Создай два файла

В рабочей папке создай каталог practice/lesson-01. Сохрани оба файла внутри него:

practice/lesson-01/
  manifest.json
  popup.html

manifest.json

{
  "manifest_version": 3,
  "name": "Lichess Training · Урок 01",
  "version": "0.1.0",
  "description": "Учебная карточка шахматного задания.",
  "action": {
    "default_title": "Тренировка сегодня",
    "default_popup": "popup.html",
    "default_area": "navbar"
  },
  "browser_specific_settings": {
    "gecko": {
      "id": "lichess-training-lesson-01@example.org",
      "data_collection_permissions": {
        "required": ["none"]
      }
    }
  }
}

manifest_version выбирает формат manifest, version — версию твоего addon. Это разные значения. Для Firefox добавлены идентификатор и описание использования данных; данный пример только показывает локальный текст. Разбор manifest у Mozilla.

popup.html

<!doctype html>
<html lang="ru">
<head>
  <meta charset="utf-8">
  <title>Тренировка сегодня</title>
</head>
<body style="width: 280px; padding: 12px; font-family: system-ui;">
  <h1>Тренировка сегодня</h1>
  <p>Задание: решить 5 задач.</p>
</body>
</html>

2. Загрузи в Firefox

  1. В адресной строке Firefox открой about:debugging#/runtime/this-firefox.
  2. Нажми Load Temporary Add-on… / «Загрузить временное дополнение».
  3. Выбери созданный practice/lesson-01/manifest.json.
  4. Нажми кнопку addon и проверь текст «Задание: решить 5 задач». Если кнопка не видна на панели, найди расширение в меню расширений Firefox.

Временная установка действует до перезапуска Firefox; после него addon загружается снова. Mozilla: временная установка и Reload.

Если загрузка не получилась

Проверь, что имя файла именно manifest.json, JSON сохранён с обычными двойными кавычками, а popup.html лежит рядом. Сообщение ошибки из about:debugging можно разобрать вместе со мной.

3. Сделай изменение сам

  1. В popup.html замени «решить 5 задач» на «решить 3 задачи».
  2. В manifest замени default_title на «Мой шахматный план».
  3. Сохрани файлы, нажми Reload у addon в about:debugging и снова открой карточку.
  4. Проверь два разных места: текст задания внутри popup и подсказку при наведении на кнопку.

Попробуй сначала предсказать, какое изменение окажется внутри карточки, а какое — на кнопке. Потом сравни с результатом.

4. Вспомни без подсказки

Не возвращаясь к фрагментам выше, проверь две ситуации. После ответа появится объяснение.

Ты переименовал popup.html в daily.html. Где исправить путь, чтобы кнопка открыла карточку?

Ты изменил default_popup в manifest. Как применить новую конфигурацию?

Что уже получилось

Через день попробуй по памяти вспомнить, где меняется текст карточки и где её путь. Затем сверись с памяткой.

Обратная связь: запиши, какой текст ты увидел после изменения и Reload. Если что-то неясно, задавай вопросы — разберём конкретный шаг.
