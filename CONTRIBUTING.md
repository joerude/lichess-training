# Как помочь проекту

Спасибо за интерес к «Шахматному журналу».

## Ошибки и идеи

Откройте [issue](https://github.com/joerude/lichess-training/issues): что делали, что ожидали, что получилось, версия Firefox и расширения. Скриншот и текст ошибки из консоли расширения (`about:debugging` → **Inspect** → Console) очень помогают.

## Изменения

1. Сделайте форк и ветку от `main`.
2. Установите зависимости: `npm ci` (нужен Node 22+).
3. Внесите изменения. Код — обычные ES modules без сборщика в `extension/`; правила дня, программы и наград — чистые функции в `extension/core/`.
4. Проверьте:
   - `npm test` — все тесты зелёные;
   - `npm run lint:addon` — без ошибок и предупреждений;
   - `npm run smoke:firefox` — если меняется интерфейс или работа с Lichess (нужен Firefox 140+; часть сценариев делает несколько запросов к lichess.org).
5. Откройте pull request с коротким описанием: что и зачем.

Интерфейс сейчас на русском. Тексты пишем коротко, подробности прячем за «?».
