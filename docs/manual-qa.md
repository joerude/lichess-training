# Проверка журнала и импорта в Firefox

Платформа: Firefox desktop 140+. Установка временная, через `about:debugging#/runtime/this-firefox`, файл `extension/manifest.json`.

Пока эти шаги не проверены в настоящем Firefox в текущей сессии: подключённый браузер для автоматизации отсутствует. Node-тесты и `web-ext lint` проверяют логику и пакет, но не заменяют эти действия.

| Шаг | Ожидаемый результат |
|---|---|
| Загрузить manifest и нажать кнопку addon | Popup показывает дату по Asia/Bishkek, задание и переход на основной экран |
| Открыть основной экран | Одно задание, профиль, цель, семь дат и резервная копия |
| Открыть задачи Lichess | Открывается `https://lichess.org/training`; собственная отметка ещё не меняется |
| Отметить выполнение | После сохранения появляются статус, сегодняшний день и общий счётчик |
| Закрыть/заново открыть popup и вкладку | Сохранённая отметка восстанавливается |
| Снять отметку и открыть экран снова | День снова ожидает выполнения |
| Открыть две вкладки и быстро отметить в обеих | Одна запись дня; нет удвоения счётчика; возвращение фокуса обновляет экран |
| Экспортировать копию | Скачивается JSON с форматом, версией, профилем, программой и днями |
| Снять отметку, выбрать копию | До подтверждения журнал не меняется; видны данные выбранной копии |
| Подтвердить восстановление | Старые данные заменяются копией; отметка и счётчик возвращаются |
| Отменить восстановление | Текущие данные не меняются |
| Выбрать неверный JSON / копию другого аккаунта | Понятная ошибка; прежние данные сохраняются |
| Перейти кнопками Tab/Enter, сузить окно | Видимый фокус, доступные подписи, текст и кнопки не обрезаются |
| Оставить экран открытым до 00:00 Asia/Bishkek | День обновляется; после возвращения из сна/другой вкладки тоже |
| Нажать выполнение в устаревшем экране | Старый клик не отмечает новый день; экран предлагает обновление |

Для ошибок IndexedDB проверь сообщение в инспекторе фоновой страницы через **Inspect** в about:debugging. Не удаляй базу ради проверки на единственной копии прогресса; сценарии отказа и отката покрываются автоматическими тестами.

## История партий

Если расширение версии 0.1.0 уже загружено, сохрани копию отметок, затем нажми Reload у addon с тем же manifest и ID. При заблокированном обновлении базы закрой остальные вкладки расширения и повтори. Обновление схемы должно сохранить отметки.

| Шаг | Ожидаемый результат |
|---|---|
| Открыть историю впервые | Понятное пустое состояние и выбор файлов |
| Выбрать games_raw.ndjson и rating_history.json из исходного датасета, проверить | 6 430 строк, 6 429 уникальных, 1 повтор, 0 пропущенных, 474 точки; база ещё не меняется |
| Сохранить | 6 429 партий; Bullet 5 917, Blitz 345, Rapid 167; отметки тренировок прежние |
| Выбрать каждый контроль и Puzzles | Видимый график, текст с датами и рейтингами; последняя дата партий 15 марта 2026 |
| Повторить проверку и сохранение тех же файлов | 0 новых, 6 429 уже существующих; число партий прежнее |
| Закрыть/открыть экран | История сохраняется; фокус или «Обновить историю» перечитывает базу |
| Выбрать NDJSON с повреждённой второй строкой | Ошибка с номером строки, прежняя история и отметки сохраняются |
| Изменить выбранный файл после предварительной проверки | «Сохранить историю» недоступна до новой проверки |
| Импортировать без JSON рейтингов | Сохранённые серии остаются; при первой загрузке график игр строится по партиям, для Puzzles нет точек |
| Восстановить резервную копию отметок после импорта | Журнал заменяется копией, 6 429 партий сохраняются |
| Сузить окно и пройти Tab/Enter | Таблица прокручивается, подписи выбора файлов и кнопки доступны, фокус виден |

Полный backup партий и автоматическое получение свежих игр остаются следующими этапами. Для повторного импорта сохраняй оригинальный датасет.

После перезапуска Firefox временный addon потребуется загрузить заново. Проверка постоянно установленного, подписанного пакета, обновления схемы и перезапуска — отдельный этап проекта. Перед экспериментами сохраняй копию: удаление расширения может удалить его локальные данные.
