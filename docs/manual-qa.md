# Проверка программы, журнала и API в Firefox

Платформа: Firefox desktop 140+. Установка временная, через `about:debugging#/runtime/this-firefox`, файл `extension/manifest.json`.

С версии 0.4.1 большая часть маршрута воспроизводится автоматически в настоящем Firefox командой `npm run smoke:firefox` (временный профиль, Marionette). Вручную остаются решение реальных задач после входа в Lichess и смена суток; остальные шаги полезно пройти руками перед публикацией.

| Шаг | Ожидаемый результат |
|---|---|
| Загрузить manifest и нажать кнопку addon | Popup показывает дату по Asia/Bishkek, задание и переход на основной экран |
| Открыть основной экран | Программа 5/5/10/1, XP, нормы на завтра, разборы, календарь и копия |
| Открыть задачи Lichess | Открывается `https://lichess.org/training`; собственная отметка ещё не меняется |
| Отметить выполнение | После сохранения появляются статус, сегодняшний день и общий счётчик |
| Закрыть/заново открыть popup и вкладку | Сохранённая отметка восстанавливается |
| Снять отметку и открыть экран снова | День снова ожидает выполнения |
| Открыть две вкладки и быстро отметить в обеих | Одна запись дня; нет удвоения счётчика; возвращение фокуса обновляет экран |
| Экспортировать копию | Скачивается JSON с форматом, версией, профилем, программой и днями |
| Снять отметку, выбрать копию | До подтверждения журнал не меняется; видны данные выбранной копии |
| Подтвердить восстановление | Старые данные заменяются копией; отметка и счётчик возвращаются |
| Отменить восстановление | Текущие данные не меняются |
| Выбрать неверный JSON / копию другого аккаунта | Понятная ошибка; прежние данные сохраняются |
| Перейти кнопками Tab/Enter, сузить окно | Видимый фокус, доступные подписи, текст и кнопки не обрезаются |
| Оставить экран открытым до 00:00 Asia/Bishkek | День обновляется; после возвращения из сна/другой вкладки тоже |
| Нажать выполнение в устаревшем экране | Старый клик не отмечает новый день; экран предлагает обновление |

Для ошибок IndexedDB проверь сообщение в инспекторе фоновой страницы через **Inspect** в about:debugging. Не удаляй базу ради проверки на единственной копии прогресса; сценарии отказа и отката покрываются автоматическими тестами.

## История партий

Если расширение версии 0.1.0 уже загружено, сохрани копию отметок, затем нажми Reload у addon с тем же manifest и ID. При заблокированном обновлении базы закрой остальные вкладки расширения и повтори. Обновление схемы должно сохранить отметки.

| Шаг | Ожидаемый результат |
|---|---|
| Открыть историю впервые | Понятное пустое состояние и выбор файлов |
| Выбрать games_raw.ndjson и rating_history.json из исходного датасета, проверить | 6 430 строк, 6 429 уникальных, 1 повтор, 0 пропущенных, 474 точки; база ещё не меняется |
| Сохранить | 6 429 партий; Bullet 5 917, Blitz 345, Rapid 167; отметки тренировок прежние |
| Выбрать каждый контроль и Puzzles | Видимый график, текст с датами и рейтингами; последняя дата партий 15 марта 2026 |
| Повторить проверку и сохранение тех же файлов | 0 новых, 6 429 уже существующих; число партий прежнее |
| Закрыть/открыть экран | История сохраняется; фокус или «Обновить историю» перечитывает базу |
| Выбрать NDJSON с повреждённой второй строкой | Ошибка с номером строки, прежняя история и отметки сохраняются |
| Изменить выбранный файл после предварительной проверки | «Сохранить историю» недоступна до новой проверки |
| Импортировать без JSON рейтингов | Сохранённые серии остаются; при первой загрузке график игр строится по партиям, для Puzzles нет точек |
| Восстановить резервную копию отметок после импорта | Журнал заменяется копией, 6 429 партий сохраняются |
| Сузить окно и пройти Tab/Enter | Таблица прокручивается, подписи выбора файлов и кнопки доступны, фокус виден |

Полный backup партий остаётся следующим этапом. Для повторного импорта сохраняй оригинальный датасет.

## Публичный API: версия 0.3.0

Загрузи тот же manifest через Reload. Сначала импортируй датасет: это задаст начало окна примерно за неделю до 15 марта. При пустой истории первое окно начинается 30 дней назад; после сохранения граница фиксируется.

| Шаг | Ожидаемый результат |
|---|---|
| Открыть экран без нажатия кнопки | Локальные счётчики и начало окна; HTTP-запросов нет |
| Сохранить импорт на открытом экране | Общая история, сегодняшние счётчики и предварительное начало окна сразу перечитываются |
| Нажать «Подключить Lichess», отказать | Нет запроса партий и записи курсора; понятная ошибка; отметки и история сохранены |
| Нажать повторно, разрешить доступ | Firefox запрашивает lichess.org и передачу имени профиля; фон делает публичный GET без cookies/токена |
| Дождаться одного запуска | До пяти порций; сохранённые партии видны, незавершённый период обозначен явно |
| Нажать остановку во время загрузки | Текущая порция завершается; новая не начинается; есть предложение продолжить |
| Закрыть экран и открыть снова | Сохранённый курсор восстановлен; новая сеть только по кнопке |
| Продолжать до конца периода | Показана исключительная верхняя граница полностью загруженного периода и дата завершения |
| Обновить повторно | То же окно перечитывается; повторные ID не удваивают игры, поздний анализ может обновить сведения |
| Отключить сеть и нажать обновление | Сообщение об ошибке, прежние числа и успешный период сохраняются |
| Вернуть сеть и повторить | После успеха ошибка скрывается, продолжение идёт с сохранённой границы |
| Оставить вкладку открытой до 00:00 Бишкек | Дата и сегодняшние счётчики переходят на новый день без сетевого запроса |
| Отозвать доступ в настройках Firefox | Следующая порция не запрашивается; панель после локального обновления предлагает подключение |
| Проверить отметку задач, её backup и Puzzles | Игры не отмечают задачи автоматически; backup v2 переносит личные записи, Puzzles — исходная серия |

HTTP 429 и таймаут потока покрыты автоматическими проверками. Не создавай частые реальные запросы ради искусственного получения 429. Отображение паузы и диалог согласия проверяются в Firefox отдельно.

После перезапуска Firefox временный addon потребуется загрузить заново. Проверка постоянно установленного, подписанного пакета, обновления схемы и перезапуска — отдельный этап проекта. Перед экспериментами сохраняй копию: удаление расширения может удалить его локальные данные.

## Ежедневная программа: версия 0.4.0

Сохрани актуальную копию перед Reload. При первом чтении новой версии программа начнётся сегодня; прежние отметки и исходная история сохранятся. Если сегодняшняя цель задач была иной, она наследуется.

| Шаг | Ожидаемый результат |
|---|---|
| Открыть программу впервые с исходным датасетом | Цели 5 Bullet / 5 Blitz / 10 задач / 1 разбор; старые мартовские игры не дают XP |
| Отметить задачи и обновить несколько раз | +20 XP за одно задание; повтор не добавляет награду |
| Снять отметку, отметить снова | −20, затем +20 XP; один день и одна награда |
| Догрузить сегодняшние игры, достигнув нормы | Игровая цель выполняется; +20 за каждый контроль; сверх нормы XP прежний |
| Сохранить разбор старой завершённой партии | Задание разбора засчитано сегодня, появляется заметка и +20 XP при норме 1 |
| Отредактировать и затем удалить заметку | Правка сохраняет дату и XP; удаление пересчитывает награду её дня |
| Изменить нормы и сохранить | Сегодняшние цели прежние; новые нормы и дата завтра показаны явно |
| Вернуться после полуночи | Новые нормы применены; XP прежних дней сохраняются; сегодняшний разбор и задачи начинаются заново |
| Написать черновик и вернуть фокус | Текст и исходная версия сохраняются; обновление фактов не стирает ввод |
| Изменить заметку из двух вкладок | Первая правка сохранена, вторая получает конфликт; черновик остаётся для сверки |
| Удалить и заново создать заметку в другом окне | Старый черновик не может перезаписать или удалить новую заметку |
| Скачать v2, изменить программу, восстановить | До подтверждения только preview; после него восстановлены нормы/отметки/заметки/XP; игры/рейтинги/курсор сохраняются |
| Выбрать старую v1-копию | Диалог описывает замену только отметок; программа и заметки сохраняются |
| Восстановить v2 в браузере без истории партий | Личные записи и игровой XP восстановлены; счётчики игр неполные до импорта, ложного выполнения 0/5 нет |
| Открыть popup | Краткая программа, число выполненных заданий, XP и уровень; ручная кнопка задач работает |
| Проверить текст 4 000 байт и неверный ID | Неверный ввод не сохраняется; понятная ошибка; черновик остаётся |
| Пройти Tab/Enter и сузить окно | Подписи, фокус, формы, карточки и ссылки доступны без обрезания |

Системная дата раньше уже сохранённых тренировок отклоняет пересчёт без записи: исправь время устройства и обнови экран. Перед публикацией отдельно проверить реальный Firefox, скачивание, диалог, обновление схемы и поведение после сна. Этот маршрут ещё не выполнен в текущей сессии.

## Автоподсчёт задач: версия 0.4.1

Перед проверкой войдите в Lichess под аккаунтом sebajun777 (в этом Firefox или в приложении): анонимно решённые задачи в счётчик профиля не попадают. Доступ к lichess.org выдаётся кнопкой «Подключить Lichess» на основном экране. Сетевые запросы видны в инспекторе фоновой части: `about:debugging#/runtime/this-firefox` → **Inspect** у расширения → вкладка Network (откройте её до popup).

| Шаг | Ожидаемый результат |
|---|---|
| Открыть popup впервые за день | «0 / 10 задач», «Начнём — 10 задач на сегодня», «счёт с ЧЧ:ММ · обновлено ЧЧ:ММ» |
| Решить 2 задачи на lichess.org/training, через минуту открыть popup | «2 / 10», полоса на 20 %, «Хорошее начало — осталось 8» |
| Открыть popup снова в течение минуты | Числа те же; нового запроса к `/api/user/` в Network фоновой части нет |
| Дорешать до нормы и открыть popup | «Норма выполнена! +20 XP», статус «✓ Засчитано по счётчику Lichess», XP в строке программы +20 |
| Решить ещё задачи, через минуту открыть popup | «Сверх нормы: N задач», где N — всего решено за день (например, 13 при норме 10); XP не растёт |
| Открыть основной экран | Задание задач засчитано, подпись «Засчитано автоматически по счётчику задач Lichess.» |
| Скачать backup v2 и восстановить его | Автоотметка («✓ Засчитано по счётчику Lichess») и +20 XP сохраняются |
| Нажать «Отменить отметку» в popup | Сразу: статус «○ Сегодня ещё не отмечено», фраза «Норма набрана — отметка снята вручную», XP −20. Через минуту при новом открытии popup автоподсчёт отметку не возвращает |
| Скачать backup v2 после отмены и восстановить его, через минуту открыть popup | Отметки нет, автоподсчёт её не возвращает |
| Отозвать доступ к lichess.org в настройках Firefox, открыть popup | «Автоподсчёт выключен: подключите Lichess на основном экране»; прежние числа с пометкой «данные могли устареть»; ручная кнопка работает |
| Вернуть доступ кнопкой «Подключить Lichess», дождаться конца загрузки партий, через минуту открыть popup | Свежие числа без пометки «данные могли устареть» |
| Отключить сеть, через минуту открыть popup | Прежние числа с пометкой «данные могли устареть» |
| Открыть popup после 00:00 по Бишкеку (доступ выдан, сеть есть) | Новый день начинается с «0 / N»; XP прошлых дней прежние |

Отдельные сценарии (каждый — в новый день или в чистом профиле):

| Шаг | Ожидаемый результат |
|---|---|
| Не открывая popup, открыть основной экран, нажать «Открыть задачи», решить 2 задачи, через минуту открыть popup | «2 / 10»; «счёт с» — время открытия основного экрана или нажатия кнопки |
| Нажать «Выполнено» при 2 / 10 и сразу «Отменить отметку»; дорешать до нормы, через минуту открыть popup | Автозачёт срабатывает: «Норма выполнена! +20 XP», «✓ Засчитано по счётчику Lichess» |
