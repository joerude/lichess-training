## Как применить датасет

1. Импортировать исходную историю и пересчитать статистику с устранением повторов.
2. Подгрузить более свежие партии и сохранить источник/дату каждого снимка.
3. Показать отдельные линии bullet, blitz, rapid и puzzles; не сравнивать их численные рейтинги как одну шкалу.
4. Отбирать завершённые партии для разборов по контролю, цвету, дебюту и наличию анализа.
5. Использовать небольшую обезличенную выборку как проверочные примеры импорта, повторной синхронизации и подсчёта задания.

Для нового XP и серий тренировок предлагается стартовать с даты начала программы. Исторические партии показывают историю, но не подтверждают выполнение новых заданий или прошлые самостоятельные разборы.

Для будущих упражнений есть конкретная стартовая выборка: 47 проанализированных blitz/rapid-партий и 118 отметок собственных Blunder при обычном сопоставлении анализа с полуходами. Например, в blitz `m8yhHud4` отмечен ход чёрных `Nxf2` на полуходе 8, с альтернативой `b8c6`; в rapid `MVymrtN4` — `Nf6` на полуходе 20, с альтернативой `f7f5`. Это кандидаты для проверки восстановленной доской и движком, не готовые задания с подтверждённым решением.

В папках `chess-analysis` и `chess-analysis-as-a-coach` уже есть программы на 30 и 21 день. Можно использовать их структуру «тактика → практика → разбор → повторение». Они привязаны к прошлой турнирной подготовке и содержат неподтверждённые прогнозы; их нагрузка, запреты и обещания рейтинга не являются текущими требованиями пользователя.

Конкретный пример для перепроверки: старый аудит заявляет 96,4% побед после трёх поражений подряд. Пересчёт уникальных партий в хронологическом порядке даёт 378 побед из 782 следующих партий — 48,34%. Причина расхождения не установлена. Дебютные и тренировочные рекомендации из прежних текстов нужно проверять по партиям, а не переносить как факты.

## Что позволяет Lichess

Публичный экспорт партий по имени пользователя поддерживает NDJSON и фильтры времени/контроля. Для счётчика завершённых партий можно начать без подключения аккаунта. [Спецификация экспорта](https://github.com/lichess-org/api/blob/master/doc/specs/tags/games/api-games-user-username.yaml).

История рейтингов доступна по категориям, но анонимный ответ может быть кэшированным или пустым; авторизованный запрос может построить её заново. [Спецификация истории рейтингов](https://github.com/lichess-org/api/blob/master/doc/specs/tags/users/api-user-username-rating-history.yaml).

Для собственных задач нужен доступ `puzzle:read`. [Спецификация активности задач](https://github.com/lichess-org/api/blob/master/doc/specs/tags/puzzles/api-puzzle-activity.yaml). Существенная деталь текущей реализации: запись привязана к паре пользователь/задача; дата обозначает первое решение, результат — последний. По этим данным нельзя восстановить каждую повторную попытку или её дату. Следовательно, API подходит для цели «попробовать N новых задач», а повторение требует отдельного учёта. Это вывод из текущего серверного кода. [PuzzleRound](https://github.com/lichess-org/lila/blob/master/modules/puzzle/src/main/PuzzleRound.scala), [выгрузка активности](https://github.com/lichess-org/lila/blob/master/modules/puzzle/src/main/PuzzleActivity.scala).

Наличие компьютерного анализа не доказывает самостоятельный разбор. В проверенной схеме экспорта нет поля «игрок разобрал партию». Для первого варианта предлагается локальная запись: партия, ключевой ход, собственный вывод и отметка завершения. [Схема партии](https://github.com/lichess-org/api/blob/master/doc/specs/schemas/GameJson.yaml).

Синхронизацию следует выполнять последовательно, сохранять результаты и повторять после сбоев. При HTTP 429 Lichess просит ждать полную минуту. [Рекомендации API](https://lichess.org/page/api-tips). OAuth с PKCE поддерживается, но обратный переход в выбранное расширение надо проверить отдельным экспериментом. [OAuth](https://github.com/lichess-org/api/blob/master/doc/specs/tags/oauth/oauth.yaml).

Игры, задачи и разборы удобно открывать на самом Lichess: уже есть [задачи по темам](https://lichess.org/training/themes), [практика](https://lichess.org/practice) и [Learn from your mistakes](https://lichess.org/@/lichess/blog/learn-from-your-mistakes/WFvLpiQA). Гипотеза ценности проекта: связать эти инструменты в персональную программу с учётом выполнения и повторения.

Разборы и упражнения по своим партиям должны относиться к завершённым играм. Помощь в выборе ходов текущей партии противоречит правилам. [Fair play](https://lichess.org/page/fair-play).

## Ограничения браузерных расширений

Chrome MV3 использует фоновый service worker, который может завершаться; состояние надо сохранять между событиями. [Жизненный цикл](https://developer.chrome.com/docs/extensions/develop/concepts/service-workers/lifecycle). Firefox использует другую конфигурацию фоновых скриптов; совместимость не получится автоматически. [MDN background](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/manifest.json/background).

Chrome `storage.local` имеет лимит 10 MB. Полную историю ходов/часов не следует без измерений складывать туда; для крупной истории надо оценить IndexedDB или хранение компактных записей. Экспорт резервной копии нужен, потому что данные локального хранилища удаляются при удалении расширения. [Chrome storage](https://developer.chrome.com/docs/extensions/reference/api/storage).

Смена тренировочного дня рассчитывается из дат при открытии/синхронизации. Фоновые alarms могут задерживаться и не обеспечивают точный ежедневный запуск. [Chrome alarms](https://developer.chrome.com/docs/extensions/reference/api/alarms). Боковая панель возможна позднее, но Chrome и Firefox используют разные API. [Chrome sidePanel](https://developer.chrome.com/docs/extensions/reference/api/sidePanel), [Firefox sidebarAction](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions/API/sidebarAction).

## Воспроизведение основной статистики

Команда только читает оригинальный NDJSON. Результат проверки: 6 430 строк, 6 429 ID и 266 партий с анализом.

```bash
python3 - <<'PY'
import json
from collections import Counter
from pathlib import Path
path = Path('/home/joerude/Desktop/lichess_dataset/games/games_raw.ndjson')
rows = [json.loads(line) for line in path.open() if line.strip()]
games = {game['id']: game for game in rows}
print('rows:', len(rows), 'unique:', len(games))
print('speeds:', Counter(game['speed'] for game in games.values()))
print('analyzed:', Counter(game['speed'] for game in games.values()
                           if game.get('analysis')))
PY
```
