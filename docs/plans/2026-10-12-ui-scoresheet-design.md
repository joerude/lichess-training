# Оформление «Турнирный бланк»: компактный popup и основной экран

Дата: 2026-10-12. Статус: стиль выбран владельцем (вариант A из трёх макетов).

## Задача

Интерфейс выглядел типовым: кремовый фон, приглушённый зелёный, терракотовый акцент, мягкие скруглённые карточки, по два-три абзаца пояснений в каждом блоке. Основной экран — длинная лента из десяти карточек с повторами (неделя показана дважды, задачи — в программе и отдельной карточкой). Нужно:

- собственный узнаваемый стиль;
- минимализм и компактность;
- длинные пояснения — по запросу, за знаком «?»;
- выбор серии рейтинга кнопками вместо выпадающего списка.

## Визуальная система

Образ — турнирный бланк записи партии: белая бумага, синие линейки, чёрные чернила, красная ручка судьи.

| Токен | Значение | Роль |
|---|---|---|
| `--page` | `#eef2f7` | фон страницы |
| `--paper` | `#ffffff` | поверхность блоков |
| `--ink` | `#111418` | текст, рамки акцентов, основные кнопки |
| `--muted` | `#5d6672` | вторичный текст |
| `--rule` | `#c5d2e4` | линейки и сетка |
| `--red` | `#c62828` | выполнено (галочки, «5/5 ✓»), ошибки |

- Шрифты лежат в пакете (`extension/fonts/`, woff2, подмножества cyrillic и latin, лицензия OFL 1.1 в `extension/fonts/OFL.txt`): **PT Serif** 400/700 для бренда, заголовков и фраз; **PT Mono** 400 для чисел, дат, времени и счётчиков; **PT Sans** 400/700 для основного текста и кнопок. Внешних запросов за шрифтами нет.
- Углы прямые (`border-radius: 0`). Сетка из линий `1px var(--rule)`, акцентные рамки и линия под шапкой — `1.5–2px var(--ink)`. Тени только «бумажные»: сдвиг `3px 3px 0 var(--rule)` у всплывающих подсказок.
- Подписи секций — PT Serif, капитель (`font-variant: small-caps`), разрядка. Никаких «эйброу» капсом над каждым заголовком.
- Кнопки: основная — заливка `--ink`, белый текст; второстепенная — прозрачная с рамкой `--ink`; тихая — текстовая. Фокус — контур `2px var(--ink)` со смещением 2px.
- Сегментированный выбор: рамка `--ink`, разделители `--ink`, выбранная кнопка залита `--ink` (`aria-pressed="true"`).
- Подсказка «?»: `<details class="hint"><summary aria-label="Подробнее">?</summary><div class="hint-body">…</div></details>`. Кружок 18px, PT Serif, рамка `--ink`. Открытая подсказка — блок на бумаге с рамкой `--ink`, шириной до ~34ch. Работает без JS и с клавиатуры.
- Прогресс задач в popup — «клетки бланка»: тот же `<progress>`, трек расчерчен на N клеток (`--cells` задаётся из JS как `min(норма, 20)`), заполнение — `--ink`.

## Popup

Сверху вниз, без лишних отступов:
1. Шапка: бренд (PT Serif) · `sebajun777` (PT Mono) · ↻. Под шапкой линия `2px --ink`.
2. Строка программы (PT Mono, мелко): «1 из 4 заданий · 20 XP · Уровень 1».
3. Карточка «Сегодня»: дата справа; «4 / 10 задач» крупно PT Mono; клетки прогресса; фраза PT Serif 700; «счёт с … · обновлено …» PT Mono; строка статуса; кнопки «Открыть задачи ↗» и «Выполнено…/Отменить отметку» в один ряд. Подпись «Автоподсчёт по профилю Lichess · Время Бишкека» уходит в «?» рядом с заголовком карточки.
4. «Открыть полный журнал →».

## Основной экран

Ширина до ~1100px, две колонки на широком экране, одна на узком. Убираются: заголовок-слоган («Время сделать ход.»), карточка «Начните с малого», дублирующая неделя («Ритм практики»), отдельная карточка «Отметок тактики» (число переезжает строкой в блок задач).

1. **Шапка**: бренд · `sebajun777` · «Обновить».
2. **Программа на сегодня** (левая колонка): дата и XP/уровень; плитки заданий сеткой бланка (Bullet, Blitz, Rapid при норме > 0, Задачи, Разбор) с крупным «N/норма» в PT Mono и «?» с пояснением плитки; неделя — семь клеток в одну строку, легенда в «?». Пояснения «Программа с …», «XP за партии…» — в «?» у XP.
3. **Задачи на Lichess** (правая колонка, бывшая `#today-card`): дата, «N задач», статус, кнопки, «Всего дней с отметкой: N» строкой PT Mono. Подпись про автоподсчёт — в «?».
4. **Партии с Lichess**: счётчики Bullet/Blitz/Rapid за сегодня в одну строку, статус, «всего в истории», кнопки. Подробности периода (`#sync-coverage`, `#sync-completed`, `#sync-last-success`) — в раскрывающемся блоке «Подробнее о загрузке». Текст согласия — в «?» у кнопки подключения.
5. **Статистика**: таблица по контролям; график рейтинга с кнопками серий **Bullet · Blitz · Rapid · Задачи**; пояснение «П / Пор / Н…» — в «?». Импорт из файлов — свёрнутый блок «Добавить историю из файлов».
6. **Нормы на завтра** и **Свой разбор** — рядом на широком экране, компактные поля; длинные подсказки — в «?».
7. **Копия**: «Скачать JSON» и «Восстановить из файла» небольшими кнопками, пояснение в «?».

## Ограничения

- Все `id`, на которые опираются `extension/ui/*.js`, тесты и `scripts/firefox-smoke.mjs`, сохраняются (или JS и тесты меняются вместе с разметкой в том же коммите). Тексты, которые проверяют тесты и smoke, не меняются.
- Выбор серии: `#history-rating-series` становится группой кнопок `role="group"` с `aria-label="Серия рейтинга"`; кнопки `data-series="Bullet|Blitz|Rapid|Puzzles"` (подпись последней — «Задачи»), выбранная — `aria-pressed="true"`, по умолчанию Bullet.
- Только `textContent`, без `innerHTML`; `web-ext lint` 0/0/0; без новых зависимостей и внешних запросов.
- Тёмная тема не делается: `color-scheme: light`, как раньше.
