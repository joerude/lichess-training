# Проверки этапа 1

4 октября 2026. Первое расширение: ручная отметка одного задания, popup, вкладка, история недели, экспорт/восстановление. Проверки ниже относятся к этому этапу, а не ко всей будущей программе.

## Выполнено

- Node 22.22.3: 56 тестов, все прошли. Проверены реальные правила, сервис, repository и транспорт сообщений; браузерное IndexedDB заменено fake-indexeddb на границе окружения.
- Повторные и одновременные отметки не дублируют день; повтор сохраняет первое время выполнения. Снятие отметки сохраняется после создания нового сервиса.
- День рассчитывается по Asia/Bishkek; старый экран после полуночи не отмечает новый день. Интерфейс отправляет показанную дату и последовательно обрабатывает запросы.
- При ошибке транзакции прежнее состояние сохраняется; успех не возвращается раньше завершения записи.
- Неверные формат/версия, профиль/часовой пояс, даты, цели, дубликаты и превышение размера резервной копии отклоняются до записи. Найденный при ревью случай sparse array закрыт проверкой всех элементов и регрессией сохранности журнала.
- Транспорт реального сервиса через background/client проверен интеграционным тестом; ответы содержат данные или ошибку. Посторонний отправитель не вызывает сервис.
- `web-ext lint`: 0 ошибок, 0 предупреждений, 0 notices. Минимум desktop 140.0; Android minimum 142.0 указан для совместимости декларации данных, Android UX не проверен.
- `web-ext build`: ZIP содержит только 14 файлов из `extension/` и записи их каталогов; каждый байт файлов совпадает с исходником на момент проверки. Ресурсы HTML и импорты ES modules разрешаются; стороннего runtime-кода и inline scripts нет.
- Четыре учебных HTML-файла/памятки: локальные ссылки разрешаются; урок 02 доступен через localhost HTTP 200. Это проверка файлов, не визуального отображения.

В текущей сессии нет подключённого браузера. Временная установка, реальный IndexedDB Firefox, скачивание файла, диалог восстановления, визуальное отображение и клавиатурная навигация **пока не проверены**. Для них подготовлен [маршрут ручной проверки](manual-qa.md).

## Инструменты разработки

`npm audit` обнаружил 3 high записи одной цепочки: `web-ext → @devicefarmer/adbkit → node-forge`. Для [RSA signature-verification advisory](https://github.com/advisories/GHSA-86w9-cpqp-85rv) исправленная версия на дату проверки не опубликована; последний node-forge — 1.4.0. Эти зависимости нужны инструментам разработки и отсутствуют в ZIP; приложение не использует Android ADB или проверку RSA через node-forge. Принудительное понижение web-ext до старой версии не применялось. Проверить обновление перед этапом подписи/постоянной установки.
