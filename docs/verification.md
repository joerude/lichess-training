# Проверки версии 0.2.0

4 октября 2026. Расширение содержит журнал тренировок и импорт исходной истории. Проверки относятся к этапам 1–2; API, дополнительные задания, самостоятельные разборы и XP остаются следующими этапами.

## История и импорт: этап 2

- Node 22.22.3: **146 тестов, 146 прошли**. Проверены нормализация, строки ошибок, профиль, фильтры, ничьи, неизвестные рейтинги, размер UTF-8 и число непустых строк, календарные даты и нулевой месяц рейтингов.
- Противоречивый game ID отклоняется, даже если одна или обе записи не подходят фильтру. Одинаковые нормализованные записи сравниваются без зависимости от порядка полей JSON и лишних исходных полей. Даты ограничены поддерживаемым четырёхзначным годом с учётом времени Бишкека.
- IndexedDB v1→v2 сохраняет прежний journal. Новые games, ratings и historyMeta записываются одной транзакцией; ошибка после успешного запроса записи отменяет весь пакет. Одновременные импорты сохраняют объединение ID без перезаписи существующих партий.
- Preview не меняет базу и не запускает программу. Импорт сохраняет отметки; восстановление backup v1 сохраняет партии. Без нового рейтингового файла прежние серии остаются.
- Интеграционный тест проходит через client, background transport, общий маршрут сервисов и реальное repository с fake-indexeddb. Ответ об общем числе партий совпадает с возвращённым обзором при двух одновременных импортах; added/existing относятся к своему пакету.
- UI последовательно обрабатывает запросы, не сохраняет до проверки, сбрасывает предварительный отчёт при смене файлов и не подтверждает устаревший выбор. Ошибка оставляет последний сохранённый обзор. Проверены очередь запросов и координаты графика для пустой, одиночной и нескольких точек.
- Исходные файлы `/home/joerude/Desktop/lichess_dataset` прочитаны через продуктовый сервис и repository: 6 430 строк, **6 429 уникальных**, 1 повтор, 0 пропущенных и 474 точки рейтинга. Первый импорт добавил 6 429; второй — 0. Отметка тренировки и история после восстановления её backup сохранены. SHA-256 исходных файлов до/после совпали.

## Журнал тренировок: этап 1

- Node 22.22.3: 59 тестов, все прошли. Проверены реальные правила, сервис, repository, транспорт сообщений и состояние сообщений интерфейса; браузерное IndexedDB заменено fake-indexeddb на границе окружения.
- Повторные и одновременные отметки не дублируют день; повтор сохраняет первое время выполнения. Снятие отметки сохраняется после создания нового сервиса.
- День рассчитывается по Asia/Bishkek; старый экран после полуночи не отмечает новый день. Интерфейс отправляет показанную дату и последовательно обрабатывает запросы.
- При ошибке транзакции прежнее состояние сохраняется; успех не возвращается раньше завершения записи.
- Неверные формат/версия, профиль/часовой пояс, даты, цели, дубликаты и превышение размера резервной копии отклоняются до записи. Найденный при ревью случай sparse array закрыт проверкой всех элементов и регрессией сохранности журнала.
- Транспорт реального сервиса через background/client проверен интеграционным тестом; ответы содержат данные или ошибку. Посторонний отправитель не вызывает сервис.
- После успешного обновления прежняя ошибка загрузки скрывается. Ошибка отдельного действия, например восстановления или экспорта, не исчезает от постороннего автоматического обновления. Проверено регрессией с наблюдаемым падением до исправления.
- `web-ext lint`: 0 ошибок, 0 предупреждений, 0 notices. Минимум desktop 140.0; Android minimum 142.0 указан для совместимости декларации данных, Android UX не проверен.
- В исходной версии 0.1.0 `web-ext build` создал ZIP из 14 файлов `extension/`; байты совпали с исходником на момент проверки. Ресурсы HTML и импорты ES modules разрешались; стороннего runtime-кода и inline scripts нет.
- Четыре учебных HTML-файла/памятки: локальные ссылки разрешаются; урок 02 доступен через localhost HTTP 200. Это проверка файлов, не визуального отображения.

## Отдельная проверка Firefox

Независимые ревью ядра и всего этапа завершены; исправлены проверка sparse arrays, путь обработчика выполнения в учебных материалах и восстановление интерфейса после временной ошибки загрузки. Итоговая узкая перепроверка поправок сохраняется в истории плана.

В текущей сессии нет подключённого браузера. Временная установка, реальный IndexedDB Firefox и его обновление схемы, выбор NDJSON/JSON, отображение SVG, скачивание файла, диалог восстановления и клавиатурная навигация **пока не проверены**. Для них подготовлен [маршрут ручной проверки](manual-qa.md).

Пакет неподписанный. Поведение постоянной установки, обновления и перезапуска проверяется на отдельном этапе. Выполнение урока пользователем пока не подтверждено.

## Инструменты разработки

`npm audit` обнаружил 3 high записи одной цепочки: `web-ext → @devicefarmer/adbkit → node-forge`. Для [RSA signature-verification advisory](https://github.com/advisories/GHSA-86w9-cpqp-85rv) исправленная версия на дату проверки не опубликована; последний node-forge — 1.4.0. Эти зависимости нужны инструментам разработки и отсутствуют в ZIP; приложение не использует Android ADB или проверку RSA через node-forge. Принудительное понижение web-ext до старой версии не применялось. Проверить обновление перед этапом подписи/постоянной установки.
