# Проверки версии 0.3.0

6 октября 2026. Расширение содержит журнал, импорт истории и ручное обновление партий из публичного API. Дополнительные задания, самостоятельные разборы и XP остаются следующими этапами. Ниже сохранены результаты предыдущих выпусков с датами и версиями.

## Публичный API: этап 3

- Node 22.22.3: **231 тест, 231 прошёл**, без skipped. `web-ext lint`: **0 ошибок, 0 notices, 0 предупреждений**. Независимая проверка интеграции и узкая перепроверка исправлений завершены без открытых замечаний.
- Полный набор Node-тестов включает HTTP-поток, состояние цикла, сервис, атомарное сохранение и интерфейс. URL запрашивает нефильтрованный экспорт по createdAt; casual, другие варианты и незавершённые записи пропускаются локально. Время ограничено поддерживаемым календарным диапазоном.
- Проверены разрыв JSON/UTF-8 между чанками, CRLF и пустые строки, ошибка поздней строки, превышение 8 МиБ/лимита записей, таймаут fetch и чтения тела, отмена потока, очистка reader и последовательные запросы.
- HTTP 429 учитывает Retry-After и минимум минуту. Пауза сохраняется в IndexedDB, переживает создание нового сервиса и отображается после одного локального перечитывания; автоматического сетевого повтора нет.
- Фиксированное окно перечитывается с начала каждого нового цикла. Проверены включительный курсор, исключительная верхняя граница, продолжение после пересоздания сервиса, позднее завершение игры, отказ при насыщенной порции без продвижения даты и сохранность состояния при ошибке.
- Games и sync metadata записываются одной транзакцией. Проверены конфликт revision, откат после успешного put, обновление позднего анализа, сохранение известных полей, отказ противоречащего ID и игнорирование более старой записи.
- Запрос разрешения начинается в click handler до await; отказ не запускает сеть. Смонтированная панель загружает до пяти порций, допускает остановку между ними, сохраняет обзор и ошибку действия. Фокус перечитывает только базу.
- После импорта сегодняшние числа, общее количество и предварительное начало окна обновляются сразу. Полночь Бишкека и возвращение после pagehide обновляют дату и локальный снимок. Отложенное обновление соседней панели не блокирует новый импорт и не снимает защиту выполняющейся записи.
- Интеграционная проверка использует настоящий поток Response, клиент HTTP, сообщения background/client, общий маршрут сервисов и repository с fake-indexeddb. Сегодняшний счётчик и общая история совпадают; ручная отметка не изменяется. График сохраняет импортированные дни и дополняется более новыми, Puzzles не обновляется по партиям.
- **Один реальный запрос** к `/api/games/user/sebajun777`, max=5, since=8 марта 2026, успешно прочитан продуктовым HTTP-клиентом: 5 строк, 5 подходящих Bullet. Это проверка контракта, не полная загрузка аккаунта и не проверка разрешений Firefox.
- Оригинальный датасет повторно проверен через сервис и repository: 6 429 добавленных, повторный импорт 0, пять API ID уже существуют. Merge не добавил дубликаты. Журнал, история и sync metadata сохранены после восстановления backup; SHA-256 обоих исходных файлов до/после совпали.
- `dist/lichess-training-0.3.0.zip` содержит **25 продуктовых файлов**; список и байты совпадают с extension. Версии manifest/package/lockfile совпадают. **146 локальных ссылок/импортов** разрешаются. Урок 04, памятка и общие CSS/JS доступны через localhost HTTP 200 и совпадают с исходниками; это проверка ресурсов, не диалогов и отображения addon.

Ограничение покрытия: API сверяет партии, начавшиеся с показанного coverageStart. История до этой даты обеспечивается импортом. Пока цикл не завершён, сегодняшние числа могут быть неполными. Backup v1 включает только отметки; полная резервная копия партий и состояния API ещё не реализована.

## История и импорт: этап 2

- Противоречивый game ID отклоняется, даже если одна или обе записи не подходят фильтру. Одинаковые нормализованные записи сравниваются без зависимости от порядка полей JSON и лишних исходных полей. Даты ограничены поддерживаемым четырёхзначным годом с учётом времени Бишкека.

## Журнал тренировок: этап 1

- Node 22.22.3: 59 тестов, все прошли. Проверены реальные правила, сервис, repository, транспорт сообщений и состояние сообщений интерфейса; браузерное IndexedDB заменено fake-indexeddb на границе окружения.
- Повторные и одновременные отметки не дублируют день; повтор сохраняет первое время выполнения. Снятие отметки сохраняется после создания нового сервиса.
- День рассчитывается по Asia/Bishkek; старый экран после полуночи не отмечает новый день. Интерфейс отправляет показанную дату и последовательно обрабатывает запросы.
- При ошибке транзакции прежнее состояние сохраняется; успех не возвращается раньше завершения записи.
- Неверные формат/версия, профиль/часовой пояс, даты, цели, дубликаты и превышение размера резервной копии отклоняются до записи. Найденный при ревью случай sparse array закрыт проверкой всех элементов и регрессией сохранности журнала.
- Транспорт реального сервиса через background/client проверен интеграционным тестом; ответы содержат данные или ошибку. Посторонний отправитель не вызывает сервис.
- После успешного обновления прежняя ошибка загрузки скрывается. Ошибка отдельного действия, например восстановления или экспорта, не исчезает от постороннего автоматического обновления. Проверено регрессией с наблюдаемым падением до исправления.
- `web-ext lint`: 0 ошибок, 0 предупреждений, 0 notices. Минимум desktop 140.0; Android minimum 142.0 указан для совместимости декларации данных, Android UX не проверен.
- В исходной версии 0.1.0 `web-ext build` создал ZIP из 14 файлов `extension/`; байты совпали с исходником на момент проверки. Ресурсы HTML и импорты ES modules разрешались; стороннего runtime-кода и inline scripts нет.
- Четыре учебных HTML-файла/памятки: локальные ссылки разрешаются; урок 02 доступен через localhost HTTP 200. Это проверка файлов, не визуального отображения.

## Инструменты разработки

`npm audit` обнаружил 3 high записи одной цепочки: `web-ext → @devicefarmer/adbkit → node-forge`. Для [RSA signature-verification advisory](https://github.com/advisories/GHSA-86w9-cpqp-85rv) исправленная версия на дату проверки не опубликована; последний node-forge — 1.4.0. Эти зависимости нужны инструментам разработки и отсутствуют в ZIP; приложение не использует Android ADB или проверку RSA через node-forge. Принудительное понижение web-ext до старой версии не применялось. Проверить обновление перед этапом подписи/постоянной установки.
