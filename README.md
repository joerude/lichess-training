# Lichess Training

Персональные программы тренировок на Lichess: задания на игры, задачи и разборы, история прогресса и геймификация. Проект также служит практикой разработки браузерных расширений.

Сейчас идёт обсуждение первой версии для **Firefox**. Главный результат через месяц — освоить разработку браузерного расширения на полезном шахматном проекте. Обучение входит в каждый этап разработки.

- [Архитектура и план](docs/architecture.md) — предложение состава продукта, модулей, правил учёта и этапов разработки. Текущий шаг — обсуждение этого документа.
- [Рабочая карта](docs/research/2026-10-04-lichess-training-discovery.md) — цель, варианты, этапы и открытые решения.
- [Данные и технические основания](docs/research/2026-10-04-lichess-training-evidence.md) — проверка собственного датасета, возможности API и ограничения расширений.
- [Учебная цель](MISSION.md) и [ресурсы Mozilla](RESOURCES.md) — основания для будущих занятий.
- [Урок 01: первый addon для Firefox](lessons/0001-firefox-first-addon.html) — учебный материал для этапа после обсуждения архитектуры.
- [Памятка: manifest и popup](reference/0001-manifest-and-popup.html) — краткое повторение первого урока.
