# Lichess Training

«Шахматный журнал» — расширение Firefox для ежедневной практики на [Lichess](https://lichess.org): программа на день из партий, задач и собственного разбора, автоматический подсчёт решённых задач, XP и уровни. Всё хранится локально в браузере, токены и пароли не нужны.

## Что умеет

- **Программа на день**: по умолчанию 5 партий Bullet, 5 Blitz, 10 задач и 1 собственный разбор. Нормы меняются на завтра.
- **Задачи считаются сами**: popup показывает «N / норма» по публичному счётчику задач профиля и засчитывает норму автоматически. Ручная отметка остаётся.
- **Партии с Lichess**: загрузка ваших партий через публичный API, счётчики за сегодня, статистика по контролям и график рейтинга.
- **Собственный разбор**: короткая заметка к партии — что решили за доской и что проверить в следующий раз.
- **XP и уровни**: 20 XP за каждое выполненное задание дня, уровень растёт каждые 100 XP.
- **Копия**: экспорт и восстановление программы, отметок, заметок и наград в JSON.

## Установка

Нужен Firefox для компьютера, версия 140 или новее.

### Постоянно (подписанный пакет)

Обычный Firefox ставит насовсем только расширения, подписанные Mozilla. Подписать свою копию можно бесплатно и без публикации в каталоге:

1. Войдите на [addons.mozilla.org](https://addons.mozilla.org/developers/addon/api/key/) и создайте API-ключи (JWT issuer и JWT secret).
2. В корне проекта выполните (нужны Node 22+ и `npm ci`):

   ```sh
   WEB_EXT_API_KEY='user:…' WEB_EXT_API_SECRET='…' npm run sign:addon
   ```

3. Откройте полученный файл `dist/*.xpi` в Firefox (перетащите в окно или `about:addons` → ⚙ → «Установить дополнение из файла»).

Для новой подписи версия в `extension/manifest.json` должна быть больше предыдущей.

### Временно (для разработки)

1. Откройте `about:debugging#/runtime/this-firefox`.
2. **Load Temporary Add-on…** → выберите `extension/manifest.json` из этого репозитория.

Временное расширение пропадает после перезапуска Firefox; загружайте его снова. Данные сохраняются, пока не нажата **Remove**.

## Как пользоваться

1. При первом запуске основной экран попросит **логин на Lichess** и **часовой пояс** (по умолчанию — пояс компьютера; по нему считается начало дня). Пароль и токен не нужны.
2. Войдите на lichess.org под этим аккаунтом (в браузере или приложении): задачи засчитываются по счётчику профиля, анонимные — нет.
3. Нажмите значок расширения → «Открыть полный журнал» → **Подключить Lichess** и разрешите доступ к lichess.org. Загрузятся ваши партии за последние недели.
4. Каждый день:
   - откройте popup **до** задач — он запомнит точку отсчёта («0 / 10», «счёт с ЧЧ:ММ»);
   - «Открыть задачи» → решайте → снова откройте popup: «N / 10», при норме задание засчитается само;
   - партии засчитываются после «Обновить с Lichess» на основном экране;
   - разбор: выберите партию, откройте её на Lichess и запишите свой вывод.
5. Знак «?» рядом с блоками раскрывает подробности.
6. Время от времени делайте «Скачать JSON» — это ваша резервная копия. Восстановить её можно только в тот же профиль: на новом компьютере сначала укажите тот же логин и пояс.
7. Сменить логин или пояс — раздел «Профиль» внизу основного экрана. Смена удаляет все локальные данные, поэтому сначала скачайте копию.

## Импорт своей истории (необязательно)

Для статистики и графика за прошлые годы можно загрузить выгрузку партий:

- партии в NDJSON: `https://lichess.org/api/games/user/ВАШ_ЛОГИН` с заголовком `Accept: application/x-ndjson` (до 20 МиБ и 100 000 строк);
- история рейтинга (необязательно): `https://lichess.org/api/user/ВАШ_ЛОГИН/rating-history`, сохранённая как JSON (до 1 МиБ).

На основном экране: «Статистика» → «Добавить историю из файлов» → выберите файлы → **Проверить файлы** → **Сохранить историю**. Повторный импорт не создаёт дублей, отметки тренировок не меняются.

## Данные и приватность

- Всё хранится в IndexedDB вашего Firefox. Сервера у расширения нет.
- После вашего разрешения расширение обращается только к публичному API lichess.org, без cookies и токенов: счётчик задач профиля и ваши партии.
- Резервная копия JSON содержит программу, отметки, заметки и награды; партии в неё не входят — их можно снова загрузить с Lichess или из файлов.

## Разработка

Node 22+ и npm:

```sh
npm ci
npm test               # модульные и интеграционные тесты (fake-indexeddb)
npm run lint:addon     # web-ext lint
npm run build:addon    # dist/lichess-training-<версия>.zip
npm run smoke:firefox  # проверка в настоящем headless Firefox через Marionette
npm run sign:addon     # подпись для постоянной установки (нужны ключи AMO)
npm run inspect:dataset -- <логин> games.ndjson [rating_history.json]
```

Код — обычные ES modules без сборщика, в `extension/`:

- `background.js` принимает команды страниц, `app/services.js` направляет их по сервисам;
- `core/` — чистые правила (дни, программа, награды, подсчёт задач);
- `data/` — IndexedDB (`repository.js`) и клиент Lichess;
- `ui/` — popup и основной экран.

`npm run smoke:firefox` запускает Firefox 140+ из `PATH` во временном профиле и проходит сценарии: первый запуск и смена профиля, без доступа, диалог разрешения, автозачёт, копия, обрыв сети, клавиатура, основной экран. Часть сценариев делает несколько реальных запросов к lichess.org; `--no-network` их пропускает, `--only=…` выбирает нужные. Сценарий `midnight` (смена суток при открытом popup) запускается только явно, с 23:50 до 23:59:40 по Бишкеку.

Подробнее: [архитектура](docs/architecture.md), [планы этапов](docs/plans/), [проверки](docs/verification.md), [ручная проверка в Firefox](docs/manual-qa.md).
