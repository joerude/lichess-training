# Lichess Training

Персональные программы тренировок на Lichess: задания на игры, задачи и разборы, история прогресса и геймификация. Проект также служит практикой разработки браузерных расширений.

Первый рабочий этап для **Firefox**: задание на 10 задач с собственной отметкой, popup, основной экран, история последних семи дней и резервная копия. Аккаунт — `sebajun777`, часовой пояс программы — `Asia/Bishkek`. Главный результат через месяц — освоить разработку браузерного расширения на полезном шахматном проекте.

Это начало программы. Импорт партий, API, несколько заданий, разборы и XP идут следующими этапами по архитектуре.

## Запустить в Firefox

Нужен Firefox desktop 140 или новее. Для временной загрузки Node не требуется.

1. Открой `about:debugging#/runtime/this-firefox`.
2. Нажми **Load Temporary Add-on…** / «Загрузить временное дополнение».
3. Выбери `/home/joerude/lichess-training/extension/manifest.json`.
4. Найди «Шахматный журнал» в меню расширений Firefox, открой popup и нажми переход на основной экран.

Задачи решаются на Lichess; выполнение подтверждаешь вручную после тренировки. Закрытие страницы сохраняет прогресс в IndexedDB. Для переноса и экспериментов используй экспорт JSON; восстановление после предварительного просмотра заменяет текущий журнал.

Временный addon исчезает из установленных после перезапуска Firefox: загрузи его заново. Подпись и постоянная установка запланированы отдельно. [Mozilla: временная установка и Reload](https://extensionworkshop.com/documentation/develop/temporary-installation-in-firefox/).

## Разработка и проверки

Node 22+ и npm нужны для тестов и упаковки. В корне проекта:

```sh
npm ci
npm test
npm run lint:addon
npm run build:addon
```

`web-ext` создаёт ZIP в `dist/`; это неподписанный пакет для разработки. Он не предназначен для обычной постоянной установки в Firefox. В ZIP входит только каталог `extension/`, без датасета, инструментов Node и уроков.

Код написан обычными ES modules без сборщика. `background.js` получает команды страниц, `app/training.js` управляет тренировкой, `core/training-engine.js` рассчитывает даты и прогресс, `data/repository.js` сохраняет журнал одной транзакцией. Локальные данные не отправляются в сеть этой версией; переход на Lichess открывает обычную страницу сайта.

Автоматические тесты используют реальные правила, сервис и repository с `fake-indexeddb` на границе браузерного хранилища. `web-ext lint` проверяет совместимость addon. [Ручная проверка Firefox](docs/manual-qa.md) остаётся отдельной: подключённого браузера в текущей сессии нет.

[Проверки и ограничения](docs/verification.md): 59 тестов прошли, lint без ошибок и предупреждений; там же описан известный audit-пункт в инструментах разработки. [Независимое ревью](docs/reviews/2026-10-04-stage1.md) завершено без открытых замечаний.
