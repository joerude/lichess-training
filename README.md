# Lichess Training

Персональные программы тренировок на Lichess: задания на игры, задачи и разборы, история прогресса и геймификация. Проект также служит практикой разработки браузерных расширений.

Рабочая версия **0.4.0 для Firefox**: ежедневная программа **5 Bullet, 5 Blitz, 10 задач, 1 собственный разбор**, XP, уровни, обзор недели и настраиваемые нормы на завтра. Партии считаются из локальной истории и публичного API; задачи отмечаются вручную; разбор требует своей заметки. Аккаунт — `sebajun777`, часовой пояс — `Asia/Bishkek`. Главный результат через месяц — освоить разработку браузерного расширения на полезном шахматном проекте.

## Запустить в Firefox

Нужен Firefox desktop 140 или новее. Для временной загрузки Node не требуется.

1. Открой `about:debugging#/runtime/this-firefox`.
2. Нажми **Load Temporary Add-on…** / «Загрузить временное дополнение».
3. Выбери `/home/joerude/lichess-training/extension/manifest.json`.
4. Найди «Шахматный журнал» в меню расширений Firefox, открой popup и нажми переход на основной экран.

Задачи решаются на Lichess; выполнение подтверждаешь вручную после тренировки. Прогресс хранится в IndexedDB. Экспорт JSON v2 содержит отметки, нормы, заметки и награды. Восстановление после предварительного просмотра заменяет их вместе; история партий, рейтинги и курсор API сохраняются. Старые копии v1 заменяют только отметки задач, сохраняя новую программу и заметки.

Временный addon исчезает из установленных после перезапуска Firefox: загрузи его заново. Подпись и постоянная установка запланированы отдельно. [Mozilla: временная установка и Reload](https://extensionworkshop.com/documentation/develop/temporary-installation-in-firefox/).

1. `/home/joerude/Desktop/lichess_dataset/games/games_raw.ndjson` — партии.
2. `/home/joerude/Desktop/lichess_dataset/rating_history.json` — необязательная история рейтингов.
3. Нажми **Проверить файлы**, затем **Сохранить историю**.

Проверка показывает 6 430 строк, 6 429 уникальных партий, один повтор и 474 точки рейтинга. После сохранения: Bullet — 5 917, Blitz — 345, Rapid — 167. Повторное сохранение добавит 0 партий. Таблица показывает победы/поражения/ничьи, долю побед, покрытие компьютерным анализом и последний рейтинг; график переключается между Bullet/Blitz/Rapid/Puzzles.

Датасет заканчивается 15 марта 2026 года. Это исходная история, которую можно заново импортировать из тех же файлов. Она не создаёт отметки сегодняшних тренировок. Без файла рейтингов график строится по последнему известному рейтингу после партии за день по времени Бишкека; Puzzles требует отдельного JSON. Некорректная строка или другой профиль отклоняют весь файл до записи. Размер партий ограничен 20 МиБ и 100 000 непустых строк, рейтингов — 1 МиБ.

## Обновить партии из Lichess

Сначала импортируй датасет, затем в карточке сегодняшних игр нажми **Подключить Lichess**. Firefox запросит доступ к lichess.org и передачу имени профиля. Запросы выполняются без токена и cookies; журнал отметок остаётся локальным. Открытие экрана и возвращение фокуса только перечитывают базу.

Один запуск читает до пяти порций по 200 строк. При незавершённом периоде нажми **Продолжить загрузку**; остановка действует после текущей порции. Сохранённый курсор переживает закрытие экрана. Счётчики учитывают завершённые rated standard партии по дню начала в Бишкеке и могут быть неполными, пока период ещё загружается.

Начало окна — последняя импортированная партия минус семь дней; без истории — последние 30 дней. Граница сохраняется после первого пакета. Каждый следующий полный цикл перечитывает это окно, чтобы подхватить позже завершённые партии и новые данные анализа. Более старые игры даёт импорт. Панель показывает начало окна и границу последнего полностью загруженного периода. Повторные ID обновляются без удвоения игр, ошибки сохраняют прежние данные, HTTP 429 включает паузу минимум на минуту.

Рейтинговый график сохраняет точки исходного JSON и продолжает их новыми дневными значениями партий. Puzzles остаётся исторической серией. Сохранённые игры выполняют игровые цели программы. Компьютерный анализ не засчитывает собственный разбор. Партии, рейтинги и курсор API в backup не входят: сохрани исходные файлы для повторного импорта.

## Программа, разборы и XP

Программа начинается при первом чтении тренировочного интерфейса новой версии. История до этого дня остаётся исходной статистикой и не приносит XP. За каждое выполненное задание дня — 20 XP; дополнительные игры сверх нормы не дают повторную награду. Уровень — `1 + floor(XP / 100)`. Снятие ручной отметки пересчитывает её XP.

В разделе разборов выбери завершённую партию из истории или введи её восьмизначный ID, открой её на Lichess и сохрани свой вывод. Новая заметка к старой партии считается в день сохранения. Одна заметка на партию; правка сохраняет первоначальную дату, удаление может снять награду этого дня. Поле принимает до 4 000 байт UTF-8. Черновик не стирается при обновлении; устаревшая правка из другого окна требует сверки с текущей записью.

Нормы настраиваются на следующий день: игры 0–100 каждого контроля, задачи 1–500, разборы 0–10; ноль отключает задание, кроме задач. Сегодняшние и прошлые цели остаются прежними. Новый календарь показывает дни выполнения всей программы; старый — только отметки задач.

Награды за игры сохраняются при переносе backup без истории. До повторного импорта XP может оставаться, а игровые задания показывать меньше фактов. Отметки задач и собственные разборы пересчитываются по восстановленным записям. V2-файл ограничен 16 МиБ; v1 — 2 МиБ.

## Разработка и проверки

Node 22+ и npm нужны для тестов и упаковки. В корне проекта:

```sh
npm ci
npm test
npm run lint:addon
npm run build:addon
npm run inspect:dataset -- /home/joerude/Desktop/lichess_dataset/games/games_raw.ndjson /home/joerude/Desktop/lichess_dataset/rating_history.json
```

`web-ext` создаёт ZIP в `dist/`; это неподписанный пакет для разработки. Он не предназначен для обычной постоянной установки в Firefox. В ZIP входит только каталог `extension/`, без датасета, инструментов Node и уроков.

Код написан обычными ES modules без сборщика. `background.js` получает команды страниц; `app/services.js` направляет их в сервис тренировок, программы, истории или обновления. Чистые модули нормализуют партии и рассчитывают статистику. `data/repository.js` сохраняет journal отдельно от games, ratings и historyMeta. `data/lichess-client.js` читает NDJSON после предоставления доступа; `app/sync.js` сохраняет партии и курсор одной транзакцией. `app/practice.js` согласует факты с программой и сохраняет отметки/награды вместе; `core/practice-engine.js` вычисляет задания и уровень.

Автоматические тесты используют реальные правила, сервис и repository с `fake-indexeddb` на границе браузерного хранилища. `web-ext lint` проверяет совместимость addon. [Ручная проверка Firefox](docs/manual-qa.md) остаётся отдельной: подключённого браузера в текущей сессии нет.

[Проверки и ограничения](docs/verification.md) описывают автоматические тесты, проверку исходного датасета и упаковки; там же описан известный audit-пункт в инструментах разработки. [Ревью этапа 1](docs/reviews/2026-10-04-stage1.md) завершено без открытых замечаний.
