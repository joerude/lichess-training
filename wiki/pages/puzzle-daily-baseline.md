Публичный счётчик Lichess ([[decision-public-puzzle-counter]]) накопительный, а нужны задачи за день по Asia/Bishkek. Поэтому первое показание дня становится точкой отсчёта, а решённое за день — разность: `solved = max(0, latest − baseline)`. День считает только `trainingDay()`; полночь Бишкека — 18:00 UTC.

## Запись
`historyMeta['puzzles']` = `{ date: 'YYYY-MM-DD', baseline, latest, baselineAt: ISO, observedAt: ISO }`: день по Бишкеку, счётчик при первом наблюдении дня, последний прочитанный счётчик, время первого наблюдения и время последнего успешного запроса. Схема IndexedDB остаётся v2 ([[data-storage-model]]). Пример из спецификации: baseline 894, latest 898 — решено 4.

## Правила (`core/puzzle-progress.js`)
1. Записи нет или `date` не сегодня: `baseline = latest = прочитанное`, `baselineAt = observedAt = сейчас`.
2. Тот же день: обновляются `latest` и `observedAt`; точка отсчёта не меняется.
3. Прочитанный счётчик меньше `baseline` (сброс или ошибка данных; в спецификации `latest < baseline`): `baseline = latest`, счёт 0.
4. Показание за сегодня моложе 60 с (`PUZZLE_REFRESH_MS = 60000`) не идёт в сеть: возвращается сохранённое. Если часы ушли назад, показание считается устаревшим.
5. Показание за вчерашний день ограничение не включает: после полуночи нужна новая точка отсчёта. Время записи берётся после запроса, чтобы показание, полученное после полуночи, открыло новый день.
6. Недопустимый счётчик (отрицательный, дробный, не число) отклоняется. Запись с нарушенной целостностью (нецелые числа, `latest < baseline`, нечитаемое время) считается отсутствующей (тесты Task 3 плана).

## Что видит карточка
В ответе `puzzles.refresh` поля `solved`, `baselineAt` и `observedAt` равны `null`, если показания за сегодня нет. При сетевой ошибке, паузе 429, `no-data` и без разрешения возвращаются последние сохранённые числа, если они за сегодня; подпись времени дополняется «· данные могли устареть». Карточка показывает «счёт с ЧЧ:ММ · обновлено ЧЧ:ММ» по времени Бишкека.

## Что не засчитывается
- Задачи, решённые до первого показания дня: точка отсчёта — первое наблюдение. Поэтому показание снимается уже при открытии popup: кнопку «Открыть задачи» нельзя нажать, не открыв popup.
- Анонимные задачи: без входа в Lichess в этом Firefox они в счётчик профиля не попадают.
- Счётчик считает все попытки, поэтому «N / норма» — число попыток, а не только успешных решений.
- Если счётчик стал меньше точки отсчёта, счёт дня снова 0 (правило 3).
