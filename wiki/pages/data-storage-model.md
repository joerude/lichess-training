# Модель данных и хранение

Решение о выборе хранилища: [[decisions-platform-and-storage]]. Модули: [[architecture-overview]].

## Записи IndexedDB
Профиль; программа и запуск; задание дня; партия; собственная отметка задач; разбор; награда; состояние синхронизации. `browser.storage.local` — только небольшие предпочтения интерфейса.

## Схема
Версия 2: journal (v1) сохранён, добавлены games, ratings, historyMeta. В 0.4.0 схема остаётся v2, в journal добавлен ключ practice рядом с state. Games и sync metadata пишутся одной транзакцией, revision отклоняет устаревшую запись.

## Награды и XP
- Выполнение и награда — одна транзакция, без сети внутри.
- ID награды `startedOn:date:taskId`; 20 XP за задание; у награды уникальный ключ; суммарный XP выводится из журнала наград; уровень вычисляется из суммы.
- Повторный импорт или синхронизация не создают второго начисления; сверх нормы XP не растёт.
- Сохранение партии/курсора и пересчёт наград — две операции; награда восстанавливается из фактов при следующем чтении.

## Резервные копии
- Backup v1 — только журнал отметок; v2 — журнал, программа, заметки, награды. Ни один формат не заменяет игры, рейтинги, sync metadata.
- Привязка к аккаунту проверяется при импорте. Данные авторизации в экспорт не попадают.
- Полная копия истории партий не реализована; история восстанавливается повторным импортом датасета.

## Правила учёта (кратко)
По умолчанию — завершённые rated standard партии выбранных контролей, ничьи учитываются; партия относится ко дню начала (точного `finishedAt` в схеме нет); часовой пояс фиксируется при запуске программы (Asia/Bishkek); изменение норм действует со следующего дня.
