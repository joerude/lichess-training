Урок для версии 0.4.0: программа по умолчанию — 5 Bullet, 5 Blitz, 10 задач, 1 собственный разбор. Игровые цели считаются по сохранённым завершённым rated standard партиям (см. [[concept-indexeddb-storage]]), задачи отмечаются вручную, разбор — это собственный вывод к партии, сохранённый в расширении.

**Факты и награды разделены.** По фактам вычисляется выполнение дня; каждое выполненное задание даёт 20 XP. ID награды: `startedOn:date:taskId`, поэтому повторное чтение или открытие popup не создаёт новую награду (идемпотентность). Отмена ручной отметки убирает XP, повторная отметка возвращает одну награду. Правка заметки сохраняет первоначальную дату разбора.

**Уровень вычисляется, не хранится:** `level = 1 + floor(totalXp / 100)`, `nextLevelXp = 100 - totalXp % 100`. Поэтому он не входит в резервную копию.

**Транзакции.** `transactPractice` сохраняет ключи `state` и `practice` store `journal` вместе; ответ даётся после события `complete` транзакции, а не после отдельного `put`. Партии API сохраняются своей транзакцией, награды пересчитываются локально при следующем чтении.

**Настройки** норм действуют со следующего дня по Бишкеку. **Backup V2** содержит отметки, правила, заметки и награды; V1 заменяет только отметки; игры, рейтинги и курсор API в копии не хранятся.

Самостоятельное упражнение: изменить расчёт уровня на 200 XP на уровень, проверить через `node --test tests/practice-engine.test.js`, затем вернуть 100.

Связи: [[lesson-03-04-history-and-lichess-api]], [[concept-message-passing-and-storage]].

> Статус освоения: упражнение и самопроверка описаны, но выполнение пользователем источники не подтверждают; урок отдельно оговаривает, что практику в Firefox пользователь выполняет самостоятельно.
