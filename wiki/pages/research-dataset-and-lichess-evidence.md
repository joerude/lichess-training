## Что позволяет Lichess
- Публичный экспорт партий NDJSON работает без аккаунта; при HTTP 429 ждать минуту. Последовательная синхронизация (реализована в [[plan-stage3-live-games]]).
- История рейтингов: анонимный ответ может быть кэширован/пуст.
- Задачи: нужен `puzzle:read`; запись на пару пользователь/задача, дата — первое решение, результат — последний, повторные попытки не восстановить. Подходит для «N новых задач», повторение нужно учитывать отдельно (вывод из кода сервера).
- В экспорте нет поля «партия разобрана» — нужна локальная запись (реализована как заметки в [[plan-stage4-daily-program]]).
- OAuth с PKCE поддерживается, возврат в расширение требует отдельной проверки. Помощь в текущей партии запрещена fair play.

## Ограничения расширений
Chrome MV3 service worker завершается, Firefox конфигурирует фон иначе; `storage.local` Chrome — 10 MB, для крупной истории рассматривать IndexedDB (выбрана в [[plan-stage1-first-training-loop]]); бэкап нужен, т.к. данные удаляются с расширением; alarms неточны — смена дня считается по датам при открытии; боковые панели различаются между браузерами.
