## Поведение
- Шаблон на день: 5 Bullet, 5 Blitz, 10 задач, 1 собственный разбор; Rapid выключен. Игры считаются из сохранённых партий по дню начала в Asia/Bishkek; задачи — ручная отметка; разбор — заметка к известной завершённой партии.
- Программа стартует в день первого открытия; старые дни и датасет наград не дают. Изменение норм действует с завтра. Пределы: 0–100 игр, 1–500 задач, 0–10 разборов.
- 20 XP за выполненное задание, сверх нормы награды нет; ID награды `startedOn:date:taskId`, идемпотентна. Уровень `1 + floor(XP/100)`. Награды задач/разборов пересчитываются при отмене; игровые сохраняются как достижения.
- Заметки: одна на game ID, до 4 000 байт, не более 1 000, оптимистическая версия для двух окон.
- Неполная загрузка API помечается: число >= цели доказывает выполнение, ниже — не доказывает отсутствие игр.

## Данные
IndexedDB остаётся v2; в `journal` ключ `practice` (правила, заметки, награды, revision, nextReviewRevision). `repository.transactPractice` пишет `journal` и `practice` в одной транзакции; сеть внутри не используется. Сервис `program.getSnapshot/configure/saveReview/deleteReview`; награды восстанавливаются из фактов при чтении.

## Backup v2
`{format, version:2, state, practice}` до 16 МиБ; v1 (до 2 МиБ) принимается, пересчитывает XP за отметки; v2 заменяет журнал, программу, заметки и награды вместе. Games/ratings/sync не трогаются. `training.previewImport` проверяет без записи.

## Риски
Неоткрытый сегодняшний день при смене норм; два окна; ошибочная последняя запись backup; закрытие после commit партии; награды до повторного импорта игр. Реальный Firefox и усвоение урока 05 проверяются отдельно.
