Правила наград

ID = startedOn:date:taskId
XP = 20 за выполненное задание дня
level = 1 + floor(totalXp / 100)
nextLevelXp = 100 - totalXp % 100

Повторное чтение использует прежний ID. Отмена ручной отметки пересчитывает XP. Разбор старой партии считается в день первого сохранения заметки; правка сохраняет эту дату и требует её текущую revision.

Награды за игры остаются достижениями при восстановлении без истории. Выполнение заданий и календарь программы вычисляются из доступных фактов; до импорта история может показывать меньше игр, чем было при получении XP.

Копия и транзакция

Backup V2 переносит отметки, правила, заметки и награды. V1 заменяет только отметки задач и сохраняет новую программу. Ни одна версия не заменяет игры, рейтинги и курсор API.

Проверка всего файла идёт до транзакции. Две записи journal сохраняются вместе; ошибка откатывает обе. Успех put — промежуточный результат, complete — завершённая транзакция. MDN: complete.

Новая партия может сохраниться раньше пересчёта программы. Следующее локальное чтение восстановит награду; HTTP для этого не нужен.
