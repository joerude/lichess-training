Manifest и popup

Минимальная карта первого учебного addon.

Где что менять

  • manifest.json — описание и конфигурация расширения.
  • name — имя расширения.
  • manifest_version — формат manifest; version — версия твоего addon.
  • action.default_title — подсказка кнопки.
  • action.default_popup — путь к HTML-карточке.
  • popup.html — текст и разметка карточки.

Mozilla: action, первое расширение.

Цикл изменения

Изменить файл → сохранить → Reload в about:debugging → открыть карточку → проверить ожидаемый результат.

Временная загрузка: about:debugging → This Firefox → Load Temporary Add-on → выбрать manifest. После перезапуска Firefox временный addon загружается снова.

Mozilla: временная установка.

Проверка памяти: если переименовать popup, исправляется путь в manifest. Если изменить текст задания, меняется HTML-карточка.
