Правила

  • Просмотр не записывает данные; сохранение начинается отдельной кнопкой.
  • В файле одинаковые нормализованные game ID объединяются, противоречащие отклоняются.
  • В базе импорт добавляет отсутствующие ID; существующая партия сохраняется как была.
  • Схема IndexedDB версии 2 добавляет games, ratings и historyMeta, сохраняя journal.
  • Месяц Lichess rating_history начинается с 0: март записан числом 2.
  • Старый компьютерный анализ не отмечает самостоятельную тренировку.
  • Backup v1 содержит журнал тренировок; партии хранятся отдельно.
