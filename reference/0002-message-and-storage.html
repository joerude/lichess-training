Команда выполнения

{
  type: "training.setCompletion",
  day: "2026-10-04",
  completed: true
}

day — дата, показанная в интерфейсе, по часовому поясу программы. Старый день нельзя случайно отметить как новый.

Что помнить

  • Источник прогресса — IndexedDB; переменные страницы временные.
  • Успех возвращается после завершения транзакции.
  • Повтор команды не создаёт вторую запись дня.
  • Экспорт создаёт файл; восстановление заменяет журнал после проверки.
